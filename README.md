# آرشیو کلاس‌ها

فایل‌های ویدیویی باید مستقیماً کنار `index.html` باشند و با الگوی `class_N.mp4` نام‌گذاری شوند.

## اجرا
در این پوشه ترمینال باز کنید و دستور زیر را اجرا کنید:

```bash
python -m http.server 8000
```

سپس در مرورگر `http://localhost:8000` را باز کنید.

## نکته
نام فایل‌های ویدیو در رابط کاربری نمایش داده نمی‌شود؛ مسیرهای واقعی همچنان بر اساس `class_1.mp4` تا `class_70.mp4` هستند.
برای سازگاری بهتر از MP4 با ویدیوی H.264 و صدای AAC استفاده کنید.
